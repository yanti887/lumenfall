LUMENFALL — Defend the Last Light. An original twin-stick arena shooter: pilot the last light-keeper ship, blast waves of void creatures, gather starshards to raise your combo, and clear all 10 waves to relight the dying star. WASD/arrows move, mouse aims, click or Space fires, Shift dashes. Synthesized WebAudio sounds, particles, screen shake, and a full HUD.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or open `game/index.html` directly — the game is plain static files with no network requests.
